# Google Docs 原生表格呈現規範

## 適用範圍

所有由 Markdown 產生、匯入或更新為 Google Docs 的研究報告、策劃規格、執行計畫、4W 進度與更新日誌。

## 強制做法

1. Markdown 表格只作版本庫原始碼；Google Docs 必須建立原生插入表格。
2. 建表前確認比較欄位。四欄以上且包含長文時，先合併可合併欄位或拆成兩張有明確用途的表格，維持可讀性。
3. 欄首必須粗體；每個儲存格以獨立內容寫入，禁止將整列以 `｜` 或 `|` 串成一段文字。
4. 每張表格建立後，核對表格列數、欄數、每個儲存格文字、欄首樣式與位置。
5. 已產生的 Google Docs 發現 Markdown 分隔文字表格時，於同一文件原位修正為原生表格，不建立副本。
6. 每次表格修正都追加至該研究主題既有的單一更新日誌，記錄變更 ID、原因與前後差異。

## 驗收條件

- 文件中無以 `｜`、`|` 或 `---` 呈現的 Markdown 表格。
- 每一張資料表可由 Google Docs 表格讀取工具辨識為原生表格。
- 每張表格的欄首與儲存格資料可與 Markdown 原始碼逐格對照。
