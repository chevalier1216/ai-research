# AI Research Harness

此資料夾是可迭代的研究作業系統；全域技能 `ai-research-harness` 則讓後續 Codex 工作自動套用相同規範。

## 研究管線

`範圍定義 → 平行找證據 → 來源驗證 → 分析 → 審核 → 報告與交接 → 每日評分`

每次 agent 交接只使用 `templates/handoff.md` 的結論欄位；來源摘錄、搜尋過程與工作草稿留在證據層，不重複帶入下游上下文。

## 現有資產

- `templates/`：報告、交接、進度更新格式。
- `evidence/`：可追溯的來源與主張紀錄。
- `reports/`：已完成報告與格式範例。
- `tool-registry.md`：工具導入決策與安全邊界。

## 每日循環的最小完成條件

1. 針對既定領域蒐集新來源，或明確記錄「無重大變化」。
2. 對每個關鍵主張更新來源與驗證狀態。
3. 產出/更新一份深度報告，或標記阻塞原因。
4. 產出 Who / What / Where / When 精簡進度。
5. 針對證據完整度、可行動性、風險未解程度評分，下一輪僅調整一個弱點。
