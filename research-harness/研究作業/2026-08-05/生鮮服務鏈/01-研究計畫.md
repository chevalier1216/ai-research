# 研究計畫與派工登錄｜臺灣生鮮食材一語句服務鏈 AI 賦能

## 研究設定

- 研究批次 ID／命題：`R-FOOD-20260805`；找出臺灣家戶由一句條件輸入（人數、天數、預算、料理時間、配送等候時間等），到餐點／食材配置、商品候選、使用者確認商家、加入購物車與結帳的服務鏈缺口與可行整合方式。
- 市場與時間邊界：臺灣為結論市場；依序比較中國大陸、其他亞太與全球案例；來源以 2026-08-05 可取得的公開一手資料為準。
- 核心問題與驗收條件：
  1. 逐段列出終端服務鏈、使用者輸入／輸出、LLM／規則／商品資料角色、商家／物流／支付依賴與失敗回復方式。
  2. 檢核食譜或餐點規劃、份量與預算換算、商品目錄對應、庫存／替代、配送條件、購物車與結帳是否已有可驗證能力；不得把未公開 API 或一鍵跨商家結帳寫成既有能力。
  3. 比較臺灣、中國大陸與亞太至少一個實際案例的功能、履約、限制與技術依賴，找出可反駁的商機缺口。
  4. 區分「AI 建議」、「使用者確認」與「零售商交易授權」；使用者選擇商家前不得自動送單、付款或承諾庫存與配送時段。
  5. 商業化架構不得只依賴 LLM：須明列 Skills、MCP 工具介面、商家即時商品／庫存／價格／配送 API 或資料同步、規則引擎、使用者確認、購物車與結帳履約的責任；MCP 不是商家 API 授權的替代品。
- 是否使用平行蒐證：是；生鮮與醫療的服務供給、競品與技術來源集合互不相依，並行可縮短關鍵路徑。
