# 研究計畫與派工登錄｜臺灣醫療資源協調與到府服務 AI 賦能

## 研究設定

- 研究批次 ID／命題：`R-HEALTH-20260805`；找出臺灣消費者從出現非緊急健康服務需求，到找到合法服務入口、完成預約／到府篩檢／諮詢銜接、追蹤履約的摩擦，以及 AI 與既有 API 可降低的非臨床摩擦。
- 市場與時間邊界：臺灣為結論市場；依序比較中國大陸、其他亞太與全球案例；來源以 2026-08-05 可取得的公開一手資料為準。
- 核心問題與驗收條件：
  1. 逐段列出終端服務鏈、使用者輸入／輸出、AI 角色、人工／持照者角色、外部服務或 API 依賴與責任邊界。
  2. 檢核「低門檻入口、到府快篩、短時結果、地圖／電話導引、服務串接」分別已有何種可驗證供給；不得把假設的 2 小時時效、可用性或醫療建議寫成事實。
  3. 比較臺灣、中國大陸與亞太至少一個實際案例的功能、履約、限制與技術依賴，找出可反駁的商機缺口。
  4. 醫療輸出僅限公開服務條件、行政準備、正式入口、地圖與聯絡資訊；不得診斷、檢傷、建議治療、選定院所或聲稱醫療適宜性。
  5. 商業化架構不得只依賴 LLM：須明列 Skills、MCP 工具介面、合作服務端 API／資料同步、規則引擎、使用者確認與履約狀態的責任；MCP 不是供應商資料授權的替代品。
- 是否使用平行蒐證：是；醫療與生鮮的服務供給、競品與法規來源集合互不相依，並行可縮短關鍵路徑。
