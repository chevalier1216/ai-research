# 研究流程治理修正報告

<!-- governance: report -->

## 修正目的

防止研究遇到缺口即新增子代理或階段，讓生鮮與醫療兩線都能維持可預期的分工、可控的交接量與可稽核的證據品質。

## 修正行動

1. 建立固定五階段與代理啟動閘門。
2. 將補證改為由原角色執行的一次性批次，最多三項缺口；補證後直接回原審核。
3. 將交接改為 ID 導向、500 字結論上限、最多 12 組主張／證據對與最多三項風險／缺口。
4. 指定 `grill-me`、`caveman` 與其他已安裝技能的適用邊界。
5. 新增機械檢查，確認流程資產包含上述控制項。
6. 更新全域 `ai-research-harness` 技能，讓後續工作預設載入相同的代理成本控制規則。

## 修正結果

兩條研究線現共用相同的流程規格、研究計畫與派工登錄、交接模板及補證登錄格式。代理數與補證範圍由事前規格控制，不再由執行途中臨時擴張。機械檢查已於 2026-08-05 通過，包含一個移除必要規則後必須失敗的負向測試。

## 修正後的預期行為

- 新研究只在命題階段決定是否使用最多兩個平行蒐集角色。
- 單一缺口不會產生新代理；審核只可前進、單次補證或停止並請示。
- 下游僅讀取必要 ID 與壓縮交接，降低重複上下文；實際 token 降幅須在下一次完整研究以執行紀錄量測，不能在修正前虛構數字。
- 獨立驗證與審核仍保留，因此減少代理不等於降低證據標準。
